# GeminiMenu

תפריט לחיצה ימנית ב-Windows 11 (בתפריט הראשי, לא תחת "הצג אפשרויות נוספות"):

- **תמלל הקלטה**: wav, mp3, m4a, ogg, amr, flac, aac, wma, opus, mp4
- **סכם לי**: pdf, txt, docx, md

בחלונית העיבוד אפשר לבחור מה להפיק: במסמכים סיכום מקוצר, נקודות עיקריות, מסקנות, משימות/תאריכים/סכומים או תשובה לשאלה חופשית; בהקלטות תמלול מדויק או נקי, תמלול עם סיכום, סיכום בלבד, פרוטוקול או הוראה חופשית. הבחירה נשארת זמינה לשינוי בזמן העיבוד.
**עריכה בסגנון ספר:** בהקלטות ("תמלול בסגנון ספר") ובמסמכים ("עריכה בסגנון ספר") אפשר לבקש שהטקסט ייערך לשפה כתובה המתאימה להדפסה: הסרת מילות מילוי, הססנות וחזרות, חיבור משפטים, חלוקה לפסקאות וכותרות משנה, ללא הוספה או השמטה של תוכן. מקומות לא ברורים מסומנים ב-`[?]` ומופיעים גם ברשימת "מקומות לבירור" בסוף. טקסט ארוך נערך בחלקים, וחלק שנקטע או נראה קצר מדי מנוסה שוב או מסומן באזהרה. קובצי PDF ארוכים מאוד עלולים להיקטע; במקרה כזה מומלץ להמיר ל-TXT או DOCX.

סיכום של הקלטה מופק בבקשת Gemini נפרדת לאחר התמלול, ומשתמש בסיכום בשלבים גם בהקלטות ארוכות. בבחירת סיכום בלבד, התמלול המלא נשמר בקובץ TXT נפרד.
אפשר לבחור אם לשמור דף HTML, קובץ TXT או את שניהם. ברירת המחדל היא HTML.
החלונית מציגה שעון ריצה, ודף HTML מציג את זמן העיבוד הכולל. התוצאה נשמרת ליד הקובץ המקורי ונפתחת אוטומטית.
דפי HTML כוללים כפתור "העתק הכל". בדפי סיכום מצוין שזהו סיכום של Gemini ולא ציטוט.
התמלול והסיכום נעשים דרך Gemini API.

קובצי שמע ווידאו ארוכים מ-5 דקות מחולקים אוטומטית לקטעי תמלול עם חפיפה קצרה. אם Gemini חותך קטע בגלל מגבלת אורך, הוא מחולק שוב לקטעים קצרים יותר.

## התקנה

1. הורד את `GeminiMenu-Setup.exe` מעמוד ה-[Releases](https://github.com/u88-1/wqu/releases/latest).
2. הפעל אותו (אם SmartScreen מזהיר: **מידע נוסף** ואז **הפעל בכל זאת**, כי הקובץ לא חתום בתעודה מסחרית).
3. הדבק מפתח API אחד או יותר: **Gemini**, **Claude** ו-**OpenAI** בשדות נפרדים. מספיק מפתח אחד. כל שדה כולל כפתור **בדוק** וקישור לקבלת מפתח.
4. לחץ **התקן / עדכן**.

ההתקנה מתבצעת בשישה שלבים ממוספרים. לכל שלב ארוך יש הגבלת זמן (עד 3 דקות לרישום החבילה), ואפשר ללחוץ **בטל** בכל רגע. אם שלב נתקע, ההתקנה לא נשארת תלויה אלא מציגה הודעה ברורה מה לעשות.

אם הוזן רק מפתח OpenAI, נבחר OpenAI לתמלול ולסיכום. אם הוזן רק מפתח Claude, נבחר Claude לעריכה ולסיכום (Claude אינו מתמלל שמע). אפשר לשנות בכל עת ב-**הגדרות**, תחת **מנועי AI ומפתחות**.

### מפתח API בחינם (Gemini)

1. היכנס ל-[https://aistudio.google.com/apikey](https://aistudio.google.com/apikey) עם חשבון Google.
2. לחץ **Create API key**.
3. הדבק את המפתח בחלון ההתקנה. המפתחות נשמרים מוצפנים ב-`%APPDATA%\GeminiMenu\config.json` (מחוץ לקוד ולריפו).

מפתחות Claude ו-OpenAI מתקבלים ב-[console.anthropic.com](https://console.anthropic.com/settings/keys) וב-[platform.openai.com](https://platform.openai.com/api-keys), והשימוש בהם מחויב בחשבון שלך אצלם.

במסלול החינמי של Gemini יש מגבלות קצב ונפח, ו-Google עשויה להשתמש בתוכן שנשלח לשיפור המוצרים שלה. מומלץ לא לשלוח כך מסמכים רגישים.

## תאריכים עבריים

בכותרת דף התוצאה מופיע התאריך הלועזי ולצידו התאריך העברי, למשל `11/11/2026 · א׳ בכסלו תשפ״ז` (אפשר לכבות בהגדרות). בסיכום מסמכים ההנחיה למודל כוללת את תאריך היום, ותאריכים עבריים שמופיעים במקור נשמרים כפי שנכתבו, בלי המרה שרירותית.

שים לב: היום העברי מתחלף בשקיעה, והתוכנה משתמשת בתאריך הלועזי של השעון ואינה מזיזה את התאריך אחרי השקיעה.

## הגדרות

`%APPDATA%\GeminiMenu\config.json`:

```json
{ "apiKey": "...", "model": "gemini-2.5-flash", "fallbackModel": "gemini-2.5-flash-lite" }
```

אם Gemini עמוס, יש עד 5 ניסיונות עם המתנה גדלה ואז מעבר למודל החלופי. אם הכול נכשל, נפתח דף שמסביר מה קרה.

### מנועי AI נוספים: Claude ו-GPT

בחלון ההגדרות, הכפתור **מנועי AI ומפתחות**:

- **תמלול הקלטות:** Gemini או OpenAI (`gpt-transcribe`). עם OpenAI נשמרת חותמת זמן אחת לכל קטע ואין תוויות דוברים. Claude אינו מקבל שמע, ולכן אינו זמין לתמלול.
- **עריכה וסיכום** (סגנון ספר, ניקוי תמלול, סיכומים, סיכום מסמכים): Gemini, Claude או OpenAI. קובץ PDF גדול מ-12MB נתמך רק עם Gemini.
- המפתחות נשמרים מוצפנים (DPAPI), ושמות הדגמים ניתנים לשינוי.
- **הנחיית סגנון ספר מותאמת:** אפשר להדביק הנחיה מלאה משלך. הכללים הטכניים (כותרות `##`, סימון `[?]`) נוספים אליה תמיד.

### שמירה כקובץ Word

בחלון הבחירה אפשר לבחור **קובץ Word (DOCX)**: פסקאות מימין לשמאל, כותרות אמיתיות (חלונית הניווט של Word), סימוני `[?]` מודגשים בצהוב, ותוויות דוברים מודגשות.

## הסרה

הפעל שוב את `GeminiMenu-Setup.exe` ולחץ **הסר התקנה**. מפתח ה-API נשאר שמור ב-AppData.

## מבנה

- `src/ShellExt`: רכיב COM (`IExplorerCommand`) שמחליט מתי להציג כל פקודה ומפעיל תהליך נפרד לכל קובץ.
- `src/App`: אפליקציה יחידה: חלונית המתנה, לקוח Gemini, יצירת הדפים והמתקין.
- `package`: מניפסט של חבילת MSIX דלילה (Sparse Package) שרושמת את הפקודות ב-Explorer.
- `.github/workflows/build.yml`: בנייה, חתימה בתעודה עצמית ופרסום ב-Releases.
